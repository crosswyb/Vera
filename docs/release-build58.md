# Vera 0.1.1 · build 58

## 更新检查

Vera 打开后会自动检查 GitHub 最新正式版，运行期间每 6 小时复查，返回前台时按间隔补查。发现新版时，顶部显示更新提示；「设置 → 通用 → 软件更新」可查看检查结果、手动重试和阅读发布说明。菜单栏与设置共用检查结果，检查不会自动下载安装或打断会议。

## 转写中断提示

转写缺口显示为「转写缺失或中断」，按音源和录音轮次列出受影响时段、原因链和错误码。详情提供对应原录音、语音转写设置和补充文字入口，便于核对与处理。已有会议可还原已保存的诊断事件，识别恢复后清除旧的错误上下文。

这次改进完善了故障说明和处理入口。真实云端故障切换、系统休眠后的恢复以及长时间会议仍需结合实际设备和服务验证。

## 升级

下载本页 DMG，等会议、导入和查证任务结束后退出 Vera，把新版拖进「应用程序」并选择「替换」。会议资料与设置保存在应用包之外。Git 标签和安装包名继续保留构建号，兼容 build 57 的检查更新功能。

本版面向 Apple 芯片 Mac，要求 macOS 26 或更新版本。
