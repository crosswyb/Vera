# Vera 0.1.1 · build 63

- **桌面恢复**　启动失败时可以原地重试。工作台连接中断时提供页面重载、服务重连和诊断复制入口，重连后恢复原页面路由。采音和收尾状态会显示在 macOS 菜单栏，采音期间禁止重启本机服务，待保存日志会在音频组件中断后保留。
- **工作台阅读**　会议列表获取失败时保留已加载内容并支持手动重试。搜索预览独立滚动并保留查看本场全部结果入口，会议纪要和查证问题页面使用更适合桌面阅读的资料卡、正文和问题列表布局。
- **纪要依据**　为全量转录片段生成稳定锚点，纪要依据显示编号、时间和原文短引，并提供 Markdown 定位链接。历史纪要缺少新字段时继续兼容渲染，会议概述在有足够转录内容时检查目的范围、过程、决定、后续动作和未决边界。

本版的离线工程验证包括 589 项测试通过、跳过 1 项，以及原生框架、云端 ASR stub、采音收尾恢复、Release 和更新安装检查通过。完整语义评估、长时音频恢复、第二台 Mac 安装和真实会议验收仍需单独执行。

本版面向 Apple 芯片 Mac，要求 macOS 26 或更新版本。
