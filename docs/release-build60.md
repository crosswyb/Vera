# Vera 0.1.1 · build 60

- **模型设置**　新建文字模型配置默认自动选择生成额度和输出上限参数。已有配置保留原值，可在高级设置里切换为「自动」。
- **会议查证与纪要**　先用本场转写中的证据给出初步回答，并改进后续查证与纪要。初步回答会标明依据和待核对的部分。
- **转写与搜索**　修复历史转写和本场搜索结果的浏览问题。导入音频时，状态栏显示该文件实际使用的转写服务。
- **识别告警**　告警会显示具体原因。可查看相关问题或忽略该项，也可以重试此前因问题编号缺少前缀而卡住的旧任务。

从 build 59 升级时，可在「设置 → 通用 → 软件更新」查看下载进度，下载完成后确认安装。安装会等正在进行的会议、导入和查证任务结束。从 build 58 或更早版本升级，请下载安装 DMG，等任务完成并退出 Vera，再将新版拖进「应用程序」并选择「替换」。

本版面向 Apple 芯片 Mac，要求 macOS 26 或更新版本。
