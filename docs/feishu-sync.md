# 在会议中把查证结果送到飞书

查证文档写入本机后，用用户授权的飞书身份，在指定的云空间文件夹创建可在手机上阅读的文档。需要会中提醒的人可以再选一个群。通知包含问题、结果摘要和云文档链接，资料不足时保留原有结论。同步默认关闭，启用时显示发送目标和范围。

## 实施顺序与验收

1. 接入官方 `lark-cli` 的原生程序，验证桌面精简环境下的身份检查、设备授权、文件夹核对、群搜索、Markdown 建文档和幂等消息。CLI 凭据由本机 CLI 管理。
2. 在本地查证文档成功保存的同一笔数据库事务记录待同步任务。独立线程处理飞书请求。开启同步之前已保存的会议文档、音频和全量转录均不进入队列。
3. 在「设置 → 飞书同步」连接账号，检查文件夹，选择是否通知群。用户可通过问号了解授权、建群、消息位置与分享权限，鼠标、键盘和点击均可操作。每次更改目的地都需要保存。
4. 用合成会议走通本地查证、生成 Markdown、创建云文档和发送通知。分别检查仅云文档、网络错误、通知失败、重启、重复处理、停用、目的地或身份变化，以及用户修改或删除原问题后的行为。
5. 用打包后的 App 检查启动和设置入口。真实租户验收由用户连接账号、选择有写权限的文件夹和测试群后执行。用手机端的目标接收账号打开链接，核对标题、摘要、引文与来源。访问权限遵循文件夹及组织的分享设置。

## 使用方法

- 已配置的飞书应用可直接登录用户账号。在授权页核对账号和应用，完成授权后返回真实交互。首次使用 CLI 的电脑需要先安装并初始化飞书应用，按设置里的使用帮助操作。
- 在飞书云空间建一个存放资料的文件夹，复制文件夹链接，在设置里核对名称。准备向同事发送时，可使用该组成员已有阅读权限的共享文件夹。
- 只想自己回看时，保存在云文档即可。想在群里收提醒时，在飞书消息中建群或选择已有群，加入接收人；用授权账号搜索并选中同名群中的正确目标。消息以所连接的用户身份发出。
- 保存配置后，「发送测试」使用固定合成内容。确认手机端可打开、目标正确，再开始会议。会中不需要等到录音结束。
- 同一个问题重新查证时，如果答案、证据和来源与上次相同，飞书保留原文档和通知。只有检索时间或生成时间变化也不会重发。结果有变化时，若同一目标已有上一版云文档，新文档和通知会标为「修订版」，文末附上一版链接。原文档中的人工批注和修改会保留。更换同步目标后，后续文档不附旧目标的链接。
- 如果云文档已创建、群通知发送失败，在同步记录中重试即可继续发送通知。若显示「结果未知」，请先到目标文件夹或群内核对，确认上次没有送达后再重试。
