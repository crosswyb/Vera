## 新用户是否能用起来

当前主链路已具备，无需 Python、Node.js 或知了 App。支持 Apple Silicon、macOS 26 及以上。安装后先在设置中检查并安装 Apple 中文模型，再填写文字模型的协议、Base URL、模型名称、API Key，以及独立的搜索服务配置（DeepSeek Search 或 Tavily）。分别测试并保存后，先导入短音频试用，再进行正式会议。实时收听还需要按所选音源完成 macOS 权限授权。完整步骤见 [安装与首次使用](../native/DISTRIBUTION.md)。

未配置云服务时可本机录音和转写；AI 纪要、问题识别与回答需要文字模型，网页查证还需要搜索。应用免费不等于第三方 API 免费。结束会议后可以恢复或重试未完成查证。

**当前交付适合小范围试用，尚不能声称陌生用户拿到就必定无障碍跑通。** 未完成的验证是第二台干净 Mac 的首次安装、首次 Apple 模型下载、权限授权和用户自行配置服务后的真实联网闭环。分发包使用 ad-hoc 本机签名，未做 Developer ID 签名与公证，因此仍可能遇到 Gatekeeper 提示；免费分发不会消除这一系统检查。安装说明已包含按 Apple 指引处理的路径。

此外，长会与睡眠/设备切换恢复、冻结样本的识别频率和查证质量评测、腾讯会议内 AI 双向发声仍不属于本次已通过的验收范围。
