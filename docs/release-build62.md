# Vera 0.1.1 · build 62

- **会议搜索**　修复 macOS 上点击「查看本场全部结果」无响应的问题，可以从搜索结果定位到原文。
- **百炼文件转写**　改为逐段上传，极短尾段与前一段一起提交。上传超时或断线时会重试当前片段一次，仍失败时保留已保存的转写和续传位置。
- **全部资料**　按会议组织目录、资料列表和正文预览。支持跨会议搜索、查看 Markdown 原文和返回原会议。窄窗口也能切换会议，阅读后可回到列表原来的位置。

从 build 61 升级时，可以在「设置 → 通用 → 软件更新」查看进度，下载完成后确认安装。如果旧版提示「更新包包含无效路径」，请下载 DMG，等会议和其他任务完成后退出 Vera，再将新版拖进「应用程序」并选择「替换」。

本版面向 Apple 芯片 Mac，要求 macOS 26 或更新版本。
