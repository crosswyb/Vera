# Vera（真实交互）0.1.0 · build 53

发布验证日期：2026-11-22。适用 Apple Silicon，最低 macOS 26。

产品英文名定为 **Vera（薇拉）**，取意于拉丁语 *veritas*（真实）。安装包、磁盘卷名和 App 英文名统一为 Vera，界面保留中文名称“真实交互”。本版完成发布隐私整改，并修正 GitHub 通用服务账户被误识别为个人用户名的问题。

## 安装与交付

下载 `Vera-0.1.0-build53-apple-silicon.dmg`，打开后将 Vera App 拖入 Applications。ZIP 提供相同应用。配置步骤见 [安装与首次使用](../native/DISTRIBUTION.md)。源码和四个发布附件通过现有 Private GitHub 仓库交付；旧版 Release 在本版远端附件校验完成后撤下。

本轮发布操作没有重启或替换现有安装版，没有修改用户会议数据。

## 隐私整改和后续防护

- 当前源码与发布可达历史清理个人绝对路径、真实会议名称和现场诊断数据。author、committer 使用 `Vera Contributors <dev@vera.invalid>`；历史改写前已在本机备份，并确认改写后的当前源码树完全一致。
- 原生组件使用 Release、源码前缀映射和签名前去除调试符号。第三方许可只保留许可文本，清理误带入的 Python 源码和缓存；原有许可文本及署名保留。
- 桌面组装、正式签名、归档及上传都调用统一隐私检查，覆盖当前源码、完整可达历史、App、冻结 Python CArchive/PYZ、嵌套 ZIP、归档名称和元数据、macOS 资源旁车、符号链接、配置和数据库、已知凭据及本机私密词典。压缩内容无法读取时停止。
- 正式签名要求工作区干净，包内源码提交与当前提交一致。发布入口重新核验签名、票据、Gatekeeper、源码、两份归档哈希和仓库 Private 状态；上传仅允许 DMG、ZIP、校验和、字段受限的验证回执，完成后对照服务器 SHA-256。
- GitHub Actions 先运行隐私回归，再扫描源码和完整历史。其 Linux 实际运行通过；仅通用 `runner`/`root` 账户名不参与字符串身份匹配，个人路径、邮箱、密钥与私密词典仍受检查。

本轮未发现真实服务 Key、私钥、会议数据库、录音或全量转写进入最终发布内容。允许的合成音频通过内容哈希确认。

**边界：** Developer ID 证书持有人姓名、团队身份以及第三方许可署名仍可读取。已改写发布可达历史；GitHub 仍能通过已知旧 SHA 读取旧提交，不能声称已清除托管平台缓存，也不能收回已被下载的旧包。扫描器不能识别任意未知自然语言中的私人信息。

可重复执行的步骤见 [发布流程](../native/RELEASING.md)。本机私密词典、历史备份、原始 Apple 日志不进入源码或发布附件。
