# 识别待处理告警：修复与验证

日期：2026-11-23。所有公开示例均为合成数据。

## 修复结果

模型把已有问题的完整 `question-` 编号漏掉固定前缀时，旧实现会将该条识别保留为“待核对”。重试又会把修正后的编号当成改变原意，因而无法完成。查看发言只能导航，也不能关闭这个告警。

现在只对本场上下文中唯一匹配的完整 16 位小写十六进制后缀补回 `question-`。原提案和重试结果先使用同一规则比较，问题版本、标题、范围和原话校验继续生效。旧提案遗漏 `expected_version` 时仍保护契约默认版本，重试不能借此覆盖较新的编辑；仅操作状态变化时单独提示状态已变化。旧任务沿用已有任务编号，保留原始提案供审计。

界面显示待处理问题和具体错误，增加“查看相关问题”与“忽略此项”。忽略记录操作者和时间，移出告警并单独计数；不把忽略算成识别成功。暂停自动查证或撤销模型授权后仍可忽略，不调用模型，也不删除发言或已有问题。

回退工具只在导出的独立副本中将已忽略任务转换为旧版可识别的结束状态，保留操作者、时间和原始提案，避免旧版重新显示无法操作的告警；源数据库保持原样。

范围补扫分别显示本范围问题及外部或未知范围的同批待处理标题，显示涉及的发言段数，并明确“忽略这段补充识别”会停止整个范围；同批其他问题不一定随之关闭。忽略请求失败且列表在轮询中更新时，当前按钮仍可重试；刷新期间切换会议后不显示旧会议的成功提示。已忽略数量追加显示，保留未完成或等待恢复的问题数量。

同批恢复任务在提交和失败收尾的事务内检查最新忽略记录，防止已经领取的补扫或重复纠正重新创建已忽略提案。不同有效问题编号始终分别处理，原话匹配同时核对实际来源及版本，重复文本的歧义来源不会自动忽略，已验证的旧上下文不制造新原话的重复歧义。坏引用只保留同标题、同来源的窄回退，引用顺序不影响匹配；通过完整识别与原意校验的纠正结果可以用另一段真实引文推翻此回退，包括只引用另一补扫范围的有效纠正，不能绕开已忽略的有效原话依据。

相同原话可以包含不同问题，匹配逐项核对有效意图字段，单个坏字段不会掩盖其他有效区别：明确不同的查证目标继续处理；只有标题不同、引文字符范围重叠或重复原话的可能位置重叠、意图依据不足时保留歧义待处理，防止重复查证或静默漏题。字段异常的原始 JSON 不参与未经校验的目标比较，不能因数组或对象类型阻塞同批正常结果。只有两个编号都能关联到本场问题时，编号不同才证明目标不同；可选搜索词被省略或为空也不能证明问题不同。同一个已有问题的不同范围修改仍核对各自原话，不能仅凭问题编号合并。候选与正式问题的分类切换本身不代表新问题，新建动作不使用的问题编号、版本和范围修改字段也不作为区别。纠正结果只有通过完整识别与原意校验后才参与忽略匹配，被拒绝的来源、缺字段或换题结果都不能结束另一条纠正任务；原提案已有明确不同的原话依据时，错误引用已忽略原话的重试保留为待处理，不能提交或结束该任务。

忽略匹配保留引用中已验证的发言编号与版本，不因多余字段丢失身份；新模型输出仍按完整契约校验。补扫上下文被裁剪时，仅为本机匹配补入原忽略提案所需、版本仍一致的发言，并将其标为旧上下文。原话在全部合格引用中先精确匹配；无精确命中时保留所有合格的标点回退位置，不能由引用顺序决定忽略哪条问题。重叠告警只有在已通过校验的结果明确落到原提案的可能位置时才完成，同标题的另一段独立原话不能清除它。

比较已有问题的忽略意图时，原提案省略的 `scope_changed` 使用契约默认值 `True`，保留同一问题后续不改变范围的单纯提及。只有修改或取消已有问题的提案显示“查看相关问题”，新建提案附带的无关问题编号不用于跳转。

补扫返回的原话因标点差异有多个匹配位置时，保留歧义供后续处理。提交前以数据库中的发言版本核对依据，避免识别过程中已更正的旧引用关闭另一条待处理告警。忽略单项时同步关闭已待处理的明确重复项。纠正成功但结果已被忽略时，清除该次运行对应的服务重试提示。

忽略时同步清理同批补扫中明确匹配的待处理提案，合并同批已忽略范围，仅清除实际新来源已全部覆盖的共享失败。忽略范围也同步结束其完全覆盖的同批单项纠正，包含已经待处理、等待执行和执行中的任务，并使旧回调失效。跨范围纠正以原提案的来源判断覆盖，重试返回较少引用不能将原本未覆盖的问题结束或提交。引用中经事件顺序验证的更早上下文不扩大忽略范围；未知来源、后续输入及其他窗口的新发言继续处理。只有已经扫描完整、当前未运行且没有剩余失败的兄弟扫描任务才直接结束；未扫描窗口继续等待处理，保留同段其他问题及后续新发言。
