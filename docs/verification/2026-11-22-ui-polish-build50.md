## 已交付

1. **完成态先呈现回答。** 有有效回答时，正文排在问题来源、操作和执行过程之前。隐藏重复的完成状态，版本移至折叠的查证过程；提供“查看原文／查看来源”入口。运行中保持进度优先，失败时保持具体原因优先。
2. **搜索本场发言或问题。** 顶栏输入和 `⌘K` 在会议内打开搜索结果，不会在输入首字后跳到会议库。搜索本机数据库中的整场最终转写与问题标题，涵盖未加载的历史发言；忽略临时转写和撤回内容。选择历史发言定位到对应时间范围，阅读期间新转写继续接收，点击“回到最新发言”恢复实时视图。`Esc` 关闭搜索并恢复焦点。另设显式的“搜索全部会议”。
3. **当前会议去重。** 已在“当前会议”呈现的会议不再重复出现在“最近打开”。
4. **错误旁单题重试。** 已有问题查证失败时，把现有“重试此问题”按钮放到错误原因旁。发言识别的恢复操作更名为“重新识别这段发言”；本场暂停时说明原因，并提供定位整场恢复操作的入口。保留“暂停自动查证期间仍可手动重试已有问题”和“结束会议后仍可恢复单题”的行为。
