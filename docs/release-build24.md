## 使用方式

应用名称、窗口标题、菜单、权限说明、安装后的 App 名称及 DMG 内应用统一为“真实交互”。本机安装位置为 `/Applications/真实交互.app`。保留原 bundle id 与本机数据库位置，使既有配置和会议继续可用。

打开“设置 → 保存与回看 → 会议文件保存位置”，可以看到完整路径，点击“打开文件夹”查看文件，或点击“选择文件夹”修改。默认路径为当前用户的 `~/Documents/ZSJH/Meetings/`，选择成功后自动保存。新会议使用新位置，已有会议及在途任务继续使用创建时绑定的位置，不自动搬迁资料。转写、纪要、录音和查证文档保存在对应会议目录。

目录需要可写，不能是文件系统根目录或已有会议目录内部。外接盘离线时保留原引用并显示访问错误，不自动在缺失挂载点建立替代目录。服务配置和数据库位置不随会议文件位置改变。会议资料没有七天自动删除规则。
