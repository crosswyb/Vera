# Vera（真实交互）0.1.0 · build 54

验证日期：2026-11-22。适用 Apple Silicon，最低 macOS 26。

本版将安装后的应用名统一为 **真实交互**，英文品牌为 **Vera**。DMG、ZIP 文件和磁盘卷名沿用 Vera；归档内只有一个 `真实交互.app`。原有应用标识、用户配置和会议资料目录继续兼容。应用菜单增加“关于真实交互”，关于窗口显示“真实交互 · Vera”。

## 审计问题与处理

| 审计项 | 核实结果及修复 |
| --- | --- |
| 快速检测把低推理强度抬到 medium | 确认存在。保留 default、none、minimal、low；仅将 high、xhigh、max 限制到 medium。问题回答和纪要不受此限制。 |
| 修改模型名称会清空通用服务 Key | 确认存在。同一服务类型和完整 Base URL 下切换模型保留当前 Key；已保存模型配置使用各自的 Key。跨域、跨路径、跨服务不继承，显式清除继续生效。 |
| Esc 关闭搜索后焦点留在输入框 | 浏览器复现。优先恢复原控件；原焦点是 body、html、已移除或不可聚焦节点时，转到主要内容。 |
| Tab 离开搜索后弹层不关闭 | 浏览器复现。离开输入框和结果区域后关闭；在两者之间移动仍保留结果。 |
| search 输入框使用不支持的 ARIA 属性 | 确认存在。保留搜索框和结果区域的语义，移除不适用的 aria-expanded，不把内容导航伪装成输入值选择器。 |
| 迟到的搜索定位覆盖历史导航 | 确认存在。更早发言、回到最新、会议切换和页面切换使旧定位失效；另补上切到会议文件、纪要或问题页的竞态。 |
| 回到最新发言未恢复跟随 | 确认存在。恢复“跟随最新”，取消等待中的历史定位。 |
| capture_finish 的 saved=false 使会议无法收尾 | 确认存在。在全部音轨已独立确认关闭且文件身份一致时允许带警告完成；缺失、改变或未关闭的录音继续拒绝，不能把真实丢失当作成功。 |
| seal.json 写入失败被忽略 | 确认存在。传播写入错误，每轮最多三次重试并保留本机记录；界面提供“重试保存”。已确认停止的音频组件不再被十秒超时监控误关；迟到错误不会自行重置重试次数，用户可修复磁盘条件后重试。 |
| 云端识别整场只重连一次 | 确认存在。改为最多三次连续重试，递增等待；有新的最终转写进展后重置，停止或撤销授权取消重连。 |
| outbox 重放会重复写入转写 | 未复现。现有录音轮次、流和序号去重有效；新增重复事件及冲突 ID 回归，不增加第二套去重机制。 |

保存事件不完整但录音可验证时，界面明确提示“部分转写未确认，请结合原录音核对”，不生成虚假的零秒缺口。

- 离线回归 497 项：496 通过、1 项真实飞书 CLI 验证按条件跳过，无失败或错误。
