# Vera 0.1.1 · build 59

## 自动下载更新

发现新的 GitHub 正式版后，Vera 会自动下载官方更新包，校验文件大小、SHA-256、应用身份、版本、Apple 签名团队和 Gatekeeper。下载完成并通过校验后，提示「安装并重新打开」或「稍后」；「设置 → 通用 → 软件更新」可查看进度、重试下载和再次发起安装。

## 确认安装与任务保护

安装需要用户确认。录音、文件导入、查证、总结或文档保存尚未结束时，Vera 会暂缓安装；确认后再次检查任务状态，无法确认状态时也会停止安装。

安装助手等待当前 App 退出后替换应用。替换或启动命令失败时尝试恢复原 App，会议资料与设置保存在应用包之外。App 所在位置需允许当前用户写入；系统接受启动命令后发生的运行故障不在自动回退范围内。

## 升级

从 build 58 或更早版本升级时，仍需下载本页 DMG，等会议、导入和查证任务结束后退出 Vera，把新版拖进「应用程序」并选择「替换」。安装本版后，后续更新才支持自动下载和确认安装。Git 标签和安装包名继续保留构建号。

本版面向 Apple 芯片 Mac，要求 macOS 26 或更新版本。
